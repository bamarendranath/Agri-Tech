# Terra — Farm Journal

Terra is a responsive farm-management web app for tracking fields, crops, and farm activities. The interface is available in French and English.

## Features

- Farm dashboard with tracked area, activity, and nitrogen summaries
- Add and manage plots, crops, and farm activities
- Store farm records locally in the browser
- Export the activity register as CSV
- Print a farm summary for reference
- Mobile-friendly layout

## Run locally

Open `index.html` in a web browser, or serve this folder with a local static web server.

## Data and reports

Farm records are stored in the browser's local storage on the current device and are not synced to other devices. CSV and printable reports are working records only; they are not official declarations and do not guarantee eligibility for subsidies. Check official requirements with the relevant authority or an agricultural adviser.
